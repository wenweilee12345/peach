# 本机测试版的语言与 VR 播放

## 界面语言

打开设置浮层，在「外观与导航」中选择 `Language / 语言`；也可在 Peach 配置的「应用与维护」中选择。支持简体中文与 English。选择保存在当前浏览器的 `peach.language.v1`，页面重新加载后生效。其他设备各自选择语言。

英文词表覆盖侧栏、管理区导航、设置浮层、主要配置分区、扫描入口、任务分区及外部播放器。来源返回的说明、运行日志与尚未接入词表的分区仍显示来源文字。影片名称、艺人名字和用户输入保持原文。

新增界面固定文案通过 `frontend/src/i18n.ts` 的 `t()` 读取词表；查询参数、路由分区名、状态键和持久偏好值继续使用原有标识。语言选择重新加载页面，使遗留壳与 React 页面使用同一份偏好，不观察或改写 DOM 内容。

## DeoVR

打开单片详情的「外部播放器 / VR」，选择 DeoVR，并按视频内容选择平面、180°、360°或鱼眼投影及单目、左右或上下布局。生成播放链接后，点击「打开 DeoVR」，或把「DeoVR 场景地址」粘贴到 DeoVR 的浏览入口。

场景地址使用 DeoVR 的公开单片 JSON 协议，`deovr://` 链接交给设备上已注册的应用。场景内的 `path` 指向同一资产的 Peach 签名流地址。场景与媒体链接共用六小时票据，绑定资产、服务进程和访问 origin；重启服务后重新生成。播放器所在设备须能访问链接中的 Peach 地址。

接口沿用 FastAPI 与既有票据和 Range 流实现，无新增运行依赖。协议来源为 [DeoVR 官方文档](https://deovr.com/documentation) 的 Single video deeplink、screenType、stereoMode 与 path 示例；不安装或捆绑 DeoVR。签名、投影参数、场景地址、鉴权与单资产范围由 API 和组件回归验证，真实头显及设备协议注册需在相应设备上验证。
